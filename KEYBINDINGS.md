# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| Super + Space | Rofi apps |
| Super + Return | Kitty |
| Super + E | Thunar |
| Super + B | Browser |
| Super + arrows | Focus |
| Super + Shift + arrows | Swap windows |
| Super + 1–9 | Workspace |
| Super + Shift + 1–9 | Move and follow |
| Super + W | Close |
| Super + F | Fullscreen |
| Super + T | Floating |
| Super + M | Monocle layout |
| Super + L | Lock |
| Super + Escape | Power menu |
| Super + V | Clipboard history |
| Print | Screenshot |
| Super + Alt + R | Restart bspwm |
| Super + Alt + K/B/P | Edit shortcuts/window manager/bar |

Media keys control volume, microphone mute and laptop brightness. After editing sxhkd, run pkill -USR1 -x sxhkd. These are proposed Omarchy-style bindings, not an exact upstream clone.
