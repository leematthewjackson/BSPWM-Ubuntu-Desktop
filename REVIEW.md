# Hardware acceptance

Use a fresh disposable Ubuntu Server 26.04 installation, with the user's existing installer choices. The base follows the working Dux setup. No custom output logging or OS regional configuration. Select LightDM if prompted. Test installation from a local console, reboot, login, networking, NVIDIA (nvidia-smi), keyboard layout, window shortcuts, wallpaper, clipboard, screenshot, sound, Bluetooth, printing, Polkit, keyring, Flatpak dialogs and suspend/resume locking. Run desktop-doctor. Record real failures; do not add speculative changes or new features. Optional vendor installers remain separate. Never run apt autoremove automatically. No production readiness claimed before successful testing.
