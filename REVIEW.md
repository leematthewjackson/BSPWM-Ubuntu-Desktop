# Claude Code review and acceptance

First do a read-only review. Report severity, file/line, evidence and proposed fix. Do not run installer or modify host until authorised. Verify Ubuntu 26.04 package candidates and paths, especially MATE Polkit, LightDM PAM, dex, Polybar tray, Light Locker and PipeWire. Check shell syntax with bash -n and ShellCheck. Compare Dux base networking logic against fresh Ubuntu Server (dracut, cloud-init, DHCP, network rollback). Check repeat installs, user ownership, backup handling, autostart duplication, stale session markers, XDG/DBus environment and session cleanup. Confirm snap purge behaviour on a fresh install. Check multi-monitor workspace allocation, X11 DPI, NVIDIA Picom and keyboard mappings.

On a disposable Ubuntu 26.04 VM, run installer, reboot, log in, run desktop-doctor. Verify app launch, tiling, navigation, swap, workspace move, fullscreen, float, monocle, screenshot, clipboard, auth prompts, keyring unlock without second password, USB mount, network shares, Bluetooth, audio, microphone, printing/scanning, Flatpak file chooser, browser screen share, monitor hotplug, power controls and actual lock/suspend security. Test clean second login and rerun installer. Repeat on ThinkPad and NVIDIA workstation only after VM pass. Record exact commands/results; distinguish manual checks from automated checks. No production readiness until all critical tests pass.
